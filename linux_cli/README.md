# The Mystery at Midnight Manor 🏚️

A Linux CLI Adventure - Follow the Clues to Solve the Mystery!

## How to Start

Read the instructions carefully, then use Linux commands to explore the files and uncover the mystery.

**Begin here:**
```bash
cd story
cat intro.txt
```

## Commands You'll Need

- `ls` - List files and folders
- `cat` - Read file contents
- `grep` - Search for text in files
- `find` - Search for files
- `wc` - Count words/lines
- `head` / `tail` - Read beginning/end of files
- `sort` - Sort file contents
- `mv` / `cd` - Navigate directories

## Tips

- Read files carefully - they contain your next clues
- Some files have hidden information
- Pay attention to file names
- Use commands to search for keywords
- Follow the breadcrumbs!

Good luck, detective! 🔍
